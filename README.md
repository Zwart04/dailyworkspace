# DailyWorkspace

Workspace harian modular untuk produktivitas pribadi: catatan, todo, bookmark, tracker pengeluaran/pemasukan, dan pengaturan.

## Fitur
- Notes: tambah/edit/hapus catatan cepat
- Todo: tambah tugas, prioritas, centang selesai, undo, hapus
- Bookmarks: kelola link penting
- Tracker: input pengeluaran dan pemasukan, ringkasan bulanan
- Settings: tema gelap/terang, prioritas default, mata uang
- Semua data tersimpan lokal via localStorage
- Modular JS modules agar mudah dikembangkan

## Live
- https://taskwell.pages.dev base template akan berkembang jadi DailyWorkspace dalam repo ini.

## Cara pakai
1. Buka live URL.
2. Pilih module dari navbar.
3. Tambah data dari form di setiap module.
4. Data tersimpan otomatis di browser.

## Target user
- Freelancer/remote worker
- Mahasiswa
- Pengguna publik yang butuh tool produktivitas simpel tanpa login
